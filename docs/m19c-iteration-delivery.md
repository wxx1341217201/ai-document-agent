# M19C Agent 优化迭代交付

日期：2026-10-13。本轮在固定 100 题上迭代，不修改任务、参考事实、允许引用范围、人工复核要求或成功阈值。

## 实现

- Plan 的规划与最终生成均传入有界会话历史。历史限 10 条、共 4,000 字符、单条 1,000 字符；旧引用 ID 被清除，历史只用于指代消解。
- 三种模式共用有界检索扩展；最多三条子查询，使用用户历史补全指代，并支持 he/she/his/her。Retrieval-First 的模型改写只能引入用户历史中的话题。
- 搜索与相邻上下文的读取上限从 1,200 提高至可配置的 4,500 字符，覆盖本次全部 249 个 chunk（最长 4,486）。总证据预算另设 8,000 token；实际展示文本与快照使用同一份受限原文前缀。
- 重叠证据只在另一已选同文档片段完整保留被删除文本时去重；引用 ID、原文前缀及源全文哈希保持可验证。重复读取不重新展示相同正文。
- ReAct 的模型轮次与工具调用预算分别管理，默认仍为 6/6。最后一轮关闭工具，超预算批次返回完整的工具协议拒绝观察后收尾。每轮首次模型请求明确选择当前知识库搜索；供应商忽略工具选择时，应用层在原预算内补做本轮检索。明确要求的元数据与相邻上下文操作同样经真实工具执行后再接受答案。
- Plan 的 PLAN/REPAIR 阶段启用可配置 JSON 输出及 1,024 token 输出上限，SYNTHESIZE 使用 2,048 token；修复仅一次，使用清洗后的具体验证错误。日志只记录阶段、耗时、调用次数与状态。
- Plan 反思会识别答案声明的证据不足，并传回含步骤、查询及当前问题的缺口摘要；仍最多一次重规划。新增可开关的结构化证据覆盖检查，检查问题各部分、引用的直接支撑、数量/单位/主体/场景；只输出覆盖状态及最多四个检索目标，不输出推理。它只读取本轮问题、实际证据和答案，不读取 benchmark 标签，也不替代人工评分。默认关闭，使用 `-VerifyPlanEvidence $true` 做明确实验。
- Plan 自动保留用户明确要求的相邻上下文步骤；共享检索的子问题保留用户原有实体/书名，“继续同一场景”会继续追溯用户原始主题，历史助手回答不能提供检索事实。
- 模型错误记录安全分类及 HTTP 状态，不记录供应商错误正文。Plan 暂时性网络/429/5xx/空响应最多重试一次，计入模型调用次数并遵守原截止时间；权限/参数错误、取消和超时不重试。可用 `AGENT_PLAN_TRANSIENT_RETRIES=0` 关闭。
- 兼容 Spring AI 2 使用的官方 SDK 异常类型，识别 `EOFException` / Socket 响应错误。ReAct 对普通工具执行失败允许一次相同调用恢复，成功后的重复调用仍受限制；无效引用草稿只允许一次修复，不回放原始无效内容或隐藏推理。
- 证据注册满额后继续处理已授权 chunk；同一 chunk 允许一致的原文前缀扩展，拒绝来源元数据变化或不一致正文。
- ReAct/Plan 搜索不再写死关闭重排；脚本的重排开关同时控制三种模式，并记录实际应用/降级结果。Agent、HTTP 读取及 HTTP 请求超时使用一致的运行参数。
- DeepSeek 官方端点显式选择非思考模式；JSON 与输出预算按阶段设置，配置可关闭。不记录或回传隐藏推理。[思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)、[JSON 输出说明](https://api-docs.deepseek.com/guides/json_mode/)。

## 指标边界

自动约束通过只意味着结构、引用来源、工具约束和状态检查通过。100 个标签及通过结果仍待人工语义复核，因此最终 TaskSuccessRate 仍不可报告为已达标。引用范围失败中存在真实重叠来源的复核候选，也存在检索偏离或答案不完整的任务，不能统一放宽判定或自动改成成功。

本轮按运行数据继续迭代，未修改原 100 题或删除引用范围校验。达到 80% 仍须完整评测及人工确认；不能把吞吐、错误率改善或 smoke 结果替代真实任务完成率。

最终仍有 39 个任务触发引用范围失败，2 个任务没有真实引用，3 个任务触发受控 INVALID_ANSWER，后者同时导致任务状态不满足（分类集合有重叠）。必需工具遗漏、步骤上限、非法计划与模型不可用在最终报告中均为 0。剩余工作应优先处理检索场景/事实与引用的对应关系、明确书名/作者等元数据意图、重规划时的证据窗口，以及覆盖检查不合规输出的修复；真实重叠来源只有复核候选，不能据此批量放宽引用范围。

## 复现

```powershell
.\mvnw.cmd '-Dmaven.compiler.fork=true' test
python benchmarks/agent/build_dataset.py --check
.\scripts\run-agent-benchmark.ps1 -Mode Live `
  -ReportDirectory reports/m19c-reproduce -Rerank $false -VerifyPlanEvidence $true `
  -AgentDeadline 120s -ModelTimeout 30s -MaxConsecutiveErrors 10 `
  -MaxRunSeconds 3600 -UseHttpsProxy
```

`UseHttpsProxy` 需要当前进程已有 `HTTPS_PROXY`；凭据从现有 `.env`/环境读取，不写入命令参数或报告。报告与观察冻结后，可用 `-Mode Audit -SourceReport <report.json>` 离线复算，用 review packet 完成人工复核后再执行 `-RequireTarget`。
