# M03 文档上传契约

`POST /api/v1/knowledge-bases/{knowledgeBaseId}/documents` 只负责验证、保存原始文件和创建 `UPLOADED` 元数据，不会同步解析正文。

同一知识库中，内容 SHA-256 相同的上传返回 `409 DUPLICATE_DOCUMENT`；不同知识库可以独立上传相同内容。该策略避免调用方误以为重复文件已经被重新保存。

删除采用受控物理删除：事务中先删除并 flush 元数据，再删除服务端生成的存储对象。对象删除失败会抛出异常并使数据库事务回滚，因此调用失败时元数据和原文件都保留。上传过程中元数据持久化失败时，会尽力删除刚存储的对象作为补偿。
