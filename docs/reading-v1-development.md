## 当前实现

- 新 reading 包：选定文档白名单、资料版本指纹、分页顺序阅读、原文引用校验。
- 新协同层：Plan / Retrieval-First / ReAct / Reflect 阶段，共享 180 秒、8 次生成、12 次工具、一次重规划。SDK maxRetries=0，许可发出前保存。
- 新 ReadingState 阶段产物与来源窗口；候选草稿不进入公开 DTO，确定性逐字原文校验后再做模型核验；反思允许撤回被新证据推翻的旧结论。
- 新任务、不可变结果版本、独立笔记与引用账本、笔记修订表、全局调度锁，迁移 V17。
- 新 /api/v1/reading/tasks 接口：创建、分页、详情、继续补全、手动恢复、按轮次取消、显式补充资料、结果版本、笔记编辑、修订与 Markdown 导出。
- 修改 RetrievalQuery / VectorQuery / KeywordQuery：可选文档集合，兼容旧构造器；Qdrant 与 ES 在候选获取时过滤，融合前再次校验。
- 前端入口、资料选择、后台任务、覆盖与阶段、结果版本、原文快照、关联追问、独立笔记编辑、AI 草稿对照与逐段采纳、修订及导出均已接入。
- 补齐 AI 新结果到达时的编辑区保留，以及保存请求期间继续输入的修改保留；冲突仍需明确对照后手动保存。
- 资料更新后可显式重开已 FULL 的任务，旧结果、笔记及引用快照保留。未知 PDF / DOCX 图像、图表、公式和扫描完整性作为覆盖边界展示，不由模型擅自清除。

## 开发边界

仓库原有大量未提交修改需要保留。本轮未获新功能发布指令，先完成开发与验证。不要输出 secrets 文件、Docker 环境、模型 Key 或数据库密码。

单轮异常恢复保留原计数和截止时间；继续补全创建新轮。任务进度会频繁改变实体 version，所以取消按轮次保护，其他状态操作仍检查 version。笔记版本独立于任务进度；混合采用旧、新结果时保存独立来源账本。
