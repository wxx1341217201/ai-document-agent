2026-10-19，根据用户对第一版视觉的偏好恢复首页层次，继续遵循根目录 `DESIGN.md`。

## 当前设计方向

- 首页保留大标题、淡彩光晕、叠放文档插画、三张入口卡片、最近资料区和页尾。
- 导航恢复双行品牌字标、工作空间标题和身份细节。
- 业务页保留直接问答、首次提问自动创建会话、运行详情及技术信息按需展开。
- 首页的三个入口分别用于整理资料、进入最近知识库提问和定位最近文档。空知识库时，提问入口引导到知识库页。
- 继续保留真实文档状态与错误；任务列表和系统诊断仍通过高级工具进入。

后续界面迭代保留首页的品牌首屏与视觉层次；简化业务操作时同时维护这些视觉元素。
